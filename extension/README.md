# Netflaz Party — ส่วนขยาย Chrome แบบ Teleparty

ดูวิดีโอพร้อมเพื่อน/แฟนบนคอมพิวเตอร์: **ใครกดเล่น/หยุด/เลื่อน ทุกคนตามกันอัตโนมัติ**
พร้อมแถบแชตด้านข้าง ทุกคนดูด้วย **บัญชีของตัวเอง** (หลักการเดียวกับ Teleparty)

ใช้ได้กับ Chrome / Edge บนคอมพิวเตอร์ (Chrome 116+) — **ไม่รองรับ iPhone** เพราะ Netflix
ไม่เล่นวิดีโอในเบราว์เซอร์มือถือ (ฝั่ง iPhone ให้ใช้แอป iOS + SharePlay ใน repo นี้)

## ทำงานยังไง

```
 แท็บของคุณ                     เซิร์ฟเวอร์ซิงก์                 แท็บของเพื่อน
 <video> ── play/pause/seek ──▶  (server/)  ──▶ สั่ง <video> ให้ตรงกัน
 แชต ◀──────────────────────────── ห้องเดียวกัน ───────────────▶ แชต
```

- `content.js` เกาะ `<video>` ในหน้า ส่งเหตุการณ์ออก และรับคำสั่งจากห้องมาใช้ โดย **กันการสะท้อนกลับ**
  (คำสั่งที่มาจากเพื่อนจะไม่ถูกส่งกลับเข้าห้องซ้ำ จึงไม่เกิดลูป)
- `background.js` ถือการเชื่อมต่อ WebSocket + ซิงก์นาฬิกาแบบ NTP เพื่อ **ชดเชยดีเลย์เครือข่าย**
  และโฮสต์ส่งตำแหน่งทุก 2 วินาทีเพื่อดึงคนที่เพี้ยนกลับ (เกิน 0.4 วิ)
- `netflix-main.js` เฉพาะบน netflix.com: เครื่องเล่น Netflix จะ error ถ้าตั้ง `currentTime` ตรงๆ
  จึงสั่ง seek ผ่านเครื่องเล่นของหน้าเว็บเอง (เท่ากับการลากแถบเวลา) — เว็บอื่นไฟล์นี้ไม่ทำอะไร

## ติดตั้ง (โหมดนักพัฒนา)

1. เปิด `chrome://extensions` → เปิด **Developer mode** (มุมขวาบน)
2. กด **Load unpacked** → เลือกโฟลเดอร์ `extension/` นี้
3. ปักหมุดไอคอน Netflaz Party ไว้บนแถบเครื่องมือ

## รันเซิร์ฟเวอร์ซิงก์

```bash
cd server && npm install && npm start   # ws://0.0.0.0:8080
```

- **ทดสอบเครื่องเดียว / วง LAN เดียวกัน:** ใช้ `ws://localhost:8080` หรือ `ws://<IP เครื่อง>:8080`
- **ดูกับเพื่อนคนละที่ (อินเทอร์เน็ต):** ต้องเอาเซิร์ฟเวอร์ขึ้นโฮสต์ที่เข้าถึงได้จากภายนอก และใช้
  `wss://` (TLS) — ดู `server/README.md`

## วิธีใช้

1. ทุกคนเปิด **เรื่องเดียวกัน** ในเว็บ (เช่น Netflix ด้วยบัญชีตัวเอง)
2. **โฮสต์:** กดไอคอนบนแท็บนั้น → ใส่ชื่อ → **สร้างห้อง (เป็นโฮสต์)** → กด **คัดลอก** รหัสห้องส่งให้เพื่อน
3. **เพื่อน:** กดไอคอนบนแท็บของตัวเอง → ใส่รหัสห้อง → **เข้าร่วมห้อง**
4. กดเล่น/หยุด/เลื่อนฝั่งไหนก็ได้ และคุยกันในแถบแชต (ปุ่ม 💬 พับ/กาง)

ถ้าเพื่อนเปิดคนละเรื่องกับโฮสต์ แถบแชตจะขึ้นเตือนพร้อมชื่อเรื่องที่โฮสต์ดูอยู่

## สิทธิ์และความเป็นส่วนตัว

- ใช้สิทธิ์ `activeTab` เท่านั้น: ส่วนขยาย **เข้าถึงได้เฉพาะแท็บที่คุณกดไอคอน** และไม่ทำงานบนเว็บอื่น
- ไม่อ่านฟอร์ม/รหัสผ่าน ไม่แตะ DRM ไม่ดึงหรือส่งต่อตัววิดีโอ — ส่งแค่ ตำแหน่งเวลา, สถานะเล่น/หยุด,
  แชต, ชื่อที่ตั้ง และ URL/ชื่อหน้าที่ดู (ไว้เช็กว่าดูเรื่องเดียวกัน) ไปยังเซิร์ฟเวอร์ที่ **คุณรันเอง**
- แชตแสดงเป็นข้อความล้วนเสมอ (กันการฝัง HTML/สคริปต์)

## ข้อจำกัดที่ควรรู้

- **ส่วน Netflix (`netflix-main.js`) ยังไม่ได้ทดสอบกับ Netflix จริง** — เทสต์อัตโนมัติรันกับ `<video>`
  บนหน้าทดสอบ เพราะในสภาพแวดล้อมที่พัฒนาไม่มีบัญชี Netflix การ seek บน Netflix อาศัยออบเจกต์เครื่องเล่น
  ภายในหน้าเว็บซึ่งไม่ได้เปิดเป็น API ทางการ Netflix อาจเปลี่ยนเมื่อไหร่ก็ได้ ถ้าใช้ไม่ได้ จะมีข้อความแจ้งให้เลื่อนเอง
  (เล่น/หยุด ยังซิงก์ได้ตามปกติ)
- ถ้ารีโหลดหน้าหรือเปลี่ยนไปเว็บอื่น ส่วนขยายจะออกจากห้อง → กดไอคอนแล้วเข้าห้องใหม่
- เบราว์เซอร์อาจบล็อกการเล่นอัตโนมัติถ้ายังไม่เคยคลิกในหน้านั้น → กดเล่นเองหนึ่งครั้ง
- อยู่ได้ทีละหนึ่งห้อง

## เรื่องข้อตกลงการใช้งาน (ToS)

ทุกคนต้องมีบัญชีของตัวเองและดูผ่านเว็บทางการ — ส่วนขยายไม่ช่วยให้ใครดูได้โดยไม่จ่ายเงิน
แต่การใช้สคริปต์ควบคุมเครื่องเล่นบนเว็บของบริการเป็น **พื้นที่สีเทาตามข้อตกลงการใช้งาน** ของบริการเหล่านั้น
(ส่วนขยายแนวนี้อย่าง Teleparty มีให้ใช้แพร่หลายมาหลายปี) ใช้เพื่อการศึกษาและรับความเสี่ยงเอง

## ทดสอบ

เทสต์อยู่ในโฟลเดอร์ `tests/` (แยกจาก `extension/` เพื่อให้โฟลเดอร์นี้ Load unpacked ได้เสมอ)

```bash
cd server && npm install                 # E2E จะเปิดเซิร์ฟเวอร์ให้เอง
cd ../tests && npm install && npx playwright install chromium
npm test        # unit: การซิงก์นาฬิกาและการชดเชยดีเลย์ใน background.js
npm run e2e     # เปิด Chromium 2 ตัวพร้อมส่วนขยาย บนหน้าที่มี <video> จริง (19 กรณี)
```

E2E ตรวจ: เข้าห้อง/บทบาท, เล่น-หยุด-เลื่อนตามกันทั้งสองทาง, ไม่เกิดลูปสะท้อน, heartbeat แก้ drift
โดยไม่สะท้อนกลับ, แชต (รวมการกันฝัง HTML), คีย์ในแชตไม่หลุดไปสั่งเครื่องเล่น, โฮสต์ออกแล้วโอนโฮสต์,
ถอดแถบแชตเมื่อออกจากห้อง และเซิร์ฟเวอร์ประมวลผลการออกจากห้องครั้งเดียว
